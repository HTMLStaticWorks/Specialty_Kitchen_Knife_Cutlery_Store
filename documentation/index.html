SECTION 01

Template Overview

STEEL & GRAIN is a commercial-grade, multi-page HTML5 template specifically designed for high-end specialty culinary knife and cutlery stores, bladesmith workshops, and culinary tool retailers.

Built on HTML5, Bootstrap 5, Vanilla CSS3 with custom properties, and pure JavaScript. It includes 13 fully realized pages, an interactive filtering/sorting engine, an image gallery with optical lightbox, form validation, and persistent dark/light theme switching.

SECTION 03

Theme System (Light & Dark)

The theme system uses CSS Custom Properties defined on :root and overrides in [data-theme="dark"]. 

/* Example in assets/css/style.css */
:root {
  --bg-primary: #FDFBF7;
  --text-primary: #1C1E21;
  --accent-brass: #C5A059;
}

[data-theme="dark"] {
  --bg-primary: #121316;
  --text-primary: #F7F5F0;
  --accent-brass: #D4B26F;
}

Theme selection is stored in localStorage.setItem('sg_theme', 'dark' | 'light') and survives across all 13 pages.

SECTION 04

Product Filtering Engine

The filtering engine in assets/js/main.js reads data attributes directly from product card containers: 

<div class="product-item-col" 
     data-type="chef" 
     data-steel="vg10" 
     data-handle="walnut" 
     data-price="240" 
     data-date="202609">
  ...
</div>

Checking any filter box dynamically scans all items in real time, updating the visible product count and re-ordering on sort selection.

SECTION 05

Adding New Products

To add a new knife or accessory to products.html, duplicate any .product-item-col block inside #productsGridContainer, specify its image and content, and adjust the data-* attributes to match your criteria.

SECTION 06

JavaScript Architecture

  • initThemeSystem(): Manages localStorage and updates sun/moon icons.
  • initStickyHeader(): Adds blur/shadow on scroll.
  • initMobileNavigation(): Controls mobile drawer and subnav accordions.
  • initProductFiltering(): Client-side filtering and sorting.
  • initProductGallery(): Thumbnail switcher on product detail page.
  • initLightbox(): High-resolution zoom overlay with ESC listener.
  • initAccordions(): FAQ expand/collapse logic.
  • initEnquiryForm(): Client-side validation and success toast.
SECTION 07

Customization & Colors

To change brand colors, edit the variables at the top of assets/css/style.css: 

--accent-brass: #C5A059;       /* Primary metallic accent */
--accent-walnut: #4A3728;      /* Wood tone accent */
--color-graphite: #16181A;     /* Dark contrasting element */
