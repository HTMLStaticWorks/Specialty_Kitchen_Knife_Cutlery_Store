# STEEL & GRAIN — Specialty Kitchen Knife & Cutlery Store HTML Template

> **"Precision Crafted for the Kitchen."**

STEEL & GRAIN is a commercial-grade, multi-page website template designed for **specialty culinary cutlery stores, custom knife makers, sharpening workshops, and artisanal kitchenware brands**.

---

## Key Features

* **13 Fully Realized HTML5 Pages**: Complete templates including two unique homepages, catalogue with multi-filter engine, product details with gallery lightbox, sharpening tiers, care guides, brand metallurgy story, inquiry forms, and error states.
* **Dual Theme Engine (Light / Dark)**: Instant toggle with `localStorage` persistence across all pages.
* **Mandatory Multi-Tier Navbar**: Sticky header with desktop dropdowns for Home (Home 1 & Home 2) and Products (8 categories), plus a responsive mobile drawer with expandable accordions.
* **Interactive Client-Side Filtering & Sorting**: Dynamic multi-attribute filtering by product type, steel core, handle material, and price range with live sorting on `products.html`.
* **Image Gallery & Optical Lightbox**: Thumbnail switcher and fullscreen zoom overlay.
* **Culinary Cutlery Focus Only**: Strictly focused on kitchen food preparation—no weapons, military, or tactical imagery.
* **Zero Lorem Ipsum**: Authentic culinary editorial copy, technical metallurgy specifications, and care instructions.
* **No Ecommerce Backend / Cart System**: Front-end product showcase designed to link to product details or direct inquiry forms.
* **Performance & SEO Ready**: Semantic HTML5, unique meta descriptions, Open Graph cards, fast loading, and keyboard accessibility.

## Quick Start

1. Open `index.html` directly in any modern web browser, or serve using any static web server:
   ```bash
   # Using Python 3
   python -m http.server 8000

   # Or using Node.js npx serve
   npx serve .
   ```
2. Navigate between pages using the sticky navbar or footer links.
3. Test dark/light mode toggle with the moon/sun button in the header.
